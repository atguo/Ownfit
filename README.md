# 衣见（Ownfit）

衣见是一款移动端个人穿搭推荐 APP：基于你的真实衣橱、个人资料、天气与使用场景给出具体搭配，并用 AI 生成"本人上身"预览，帮助你在穿衣出门前判断一套衣服穿在自己身上是否合适。

> 核心目标：**帮助用户从自己的真实衣橱中，选出适合自己、实际愿意穿的搭配。**

## 为什么做这款 APP

同样一件衣服，在不同身材、外貌与发型的人身上效果不同。参考别人买回来的衣服常常不适合自己，衣柜里已有的衣服也难以组合。衣见不从"生成一张好看的穿搭图"出发，而是从你真实拥有的衣服出发：每一次推荐都对应具体单品、有据可依，是可以实际穿出门的搭配。

## 核心能力链路

1. **理解真实衣物与需求** —— 从一次搭配任务开始轻量建档，结合当次场景与偏好；首次使用无需先录完整衣橱。
2. **基于已有衣橱推荐具体搭配** —— 组合有依据、符合需求，支持锁定单品、局部替换与撤销。
3. **AI 本人上身预览** —— 尽量保留本人与真实衣物特征，按需比较不同方案的上身效果，辅助判断。
4. **实际穿着反馈验证** —— 区分"图片好看""愿意收藏"与"穿过后确实满意"，让穿后满意的方案持续复用。

## 产品目标

- **选对穿搭**：预览是否接近实际穿着、能否改善选择，是产品价值的关键；图片好看不能代替人物、衣服与上身效果的真实性。
- **低录入负担**：优先自动提取、复用与少量必要确认，不依赖大量手工录入或完整测量。
- **资料归属本地**：衣橱、照片、方案与反馈全部保存在设备本地，不建云端资料库、账号系统或跨设备同步；AI 接口由用户自行配置，APP 不内置模型。
- **成功标准**：用户按推荐与预览选中的搭配，在真实穿着后仍然满意，且建立衣橱的工作量可接受。

## 当前进展

- 可行性验证与里程碑 M0–M5 已完成验收：搭配推荐、AI 上身预览、穿着反馈记录等核心链路已在客户端实现并通过自动回归。
- M6 真机质量验证进行中：release 构建与升级链路已收口，真机走查清单与模型效果校准（生成后核对、纠偏、同条件比较）尚未完成。
- **验证边界**：模型实际效果与真实试穿对照尚未验证，效果结论未知；不以自动化测试通过等同于真机验收或模型效果达标。

详细过程与证据见 [里程碑实施记录](docs/里程碑实施记录.md)，当前实施边界见 [AGENTS.md](AGENTS.md)。

## 未来期望

按产品阶段持续推进，详细范围见 [项目计划书](docs/项目计划书.md) 与 [开发计划](docs/开发计划.md)：

- **个性化优化**：完善自然反馈与满意方案复用，让推荐随实际穿着数据逐步变准；逐步扩展起点与服装品类。
- **灵感与补购**：优先验证具体待购商品能否融入已录入衣橱，再扩展概念搭配、自动找款与购买前后验证，形成从灵感到实物的完整流程。
- **真实性持续验证**：以真实试穿对照检验预览可信度，不足处收窄能力承诺并继续验证，不以图像美观代替产品目标。
