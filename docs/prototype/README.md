# 第一版 UI 原型基准

日期：2026年10月26日  
状态：用户已认可此原型作为第一版 UI 落地依据。

## 入口与范围

源文件位于 [prototype/index.html](../../prototype/index.html)，在项目根目录执行 `node prototype/server.cjs` 后，使用 `http://127.0.0.1:4173` 浏览。服务只监听本机；浏览器之外的真实设备接入不是当前服务的默认能力。

原型覆盖今天首页、衣橱、轻量添加、选择基础单品、搭配与局部替换、穿法、示例预览、收藏反馈、个人偏好和场景弹层。桌面两侧展示说明不属于 APP。

视觉方向：雾白 `#FAFBF8`、墨绿 `#24483E`、灰绿 `#A6B3A0`，以图片、留白和少量强调色构建层级。沿用视觉意图，在 RN 中结合真机文字、触控、安全区域和系统导航实现，不要求照搬 CSS 尺寸。

## 基准边界

原型是 HTML/CSS/JavaScript 交互示意，不是 RN 工程。人物、衣物与天气含演示数据；图片由内置 imagegen 生成，预览为预制示例。无真实 AI、天气服务、账号或云端任务；本地浏览器操作不证明移动端后台恢复或试穿准确性。

功能规则以 [功能文档](../functions/README.md) 为准。原型中的固定组合、示例数据、部分模拟状态不能作为删减规则或生产实现的依据。
