本目录是 A 工作线（AI 可行性与试穿验证）的实验脚本区。协作约束以仓库根 [AGENTS.md](../../AGENTS.md) 为准；实验设计依据 [docs/开发计划.md](../../docs/开发计划.md) A 工作线与 [docs/functions/AI上身预览.md](../../docs/functions/AI上身预览.md)。

## 红线

1. **凭证**：API Key 只存本机 `.env`（git 忽略）。不得写进代码、记录文件、日志、对话或版本库。
2. **样本隐私**：真人/衣物照片只存 `samples/`（git 忽略）；参与者同意与用途、保存期限记录按 AI 上身预览文档 §8.3 留存在样本目录。记录文件只引用样本文件名，不内嵌图片数据。
3. **结论边界**：只有真实样本能产生实验结论；占位图仅用于验证脚本流程，其结果必须标注"流程验证，非结论"。真实试穿未做前，不对上身预览真实性做任何评价。
4. **费用**：每次跑批前打印调用次数并要求确认（`--yes`）；费用走项目用户自己的服务账号。
5. **契约边界**：本包内的 zod schema 依据功能文档字段归纳，用于实验内校验；它不是 M3 业务契约，M3 契约草案另按开发计划 §6.3 形成。契约包不得在草案前虚构字段。

## 记录规范

- 每次真实模型调用都通过 `src/lib/records.ts` 落 JSONL（`records/<workflow>/`），含：时间、服务与模型、输入引用、原始返回、耗时、解析结果、人工核对回填位。
- 失败样本与"看不清/不确定"一样有记录价值，不得只保留成功结果。
- 人工核对后回填 `review` 字段；小样本结论以 Markdown 报告沉淀在对应工作流目录。
