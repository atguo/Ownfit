# M5 真实推荐与 AI 预览闭环：实施计划

日期：2026-10-30 · 实施版 v1 · 依据：[开发计划 §7 M5](../开发计划.md)；项目用户 2026-10-30 指示开始 M5（M4 视同验收，随步骤 0 登记）。

## 步骤 0：M4 收尾

里程碑状态：M4 完成并验收（2026-10-30 adb 真机验证通过 + 项目用户指示进入 M5）。

## 依赖与放行（§7 M5"按能力放行"）

- **轨 A 上身预览**：证据已有（A-上身预览 MiniMax `image-01` 连通性测试通过，`minimaxClient.generateImage` 已实现）；人物参考需用户准备肖像照；整体验收需真实试穿对照记录（用户线下参与）。
- **轨 B 搭配推荐**：A-搭配推荐此前顺延、无早期结果——**实验先行**（experiments 包恢复该工作流），证据产出后再接入 APP；接入失败保留手动组合（M3 现状兜底）。
- **轨 C 自动天气**：可选联网、失败保留手动；不发衣橱/人物资料。

## 轨 A：上身预览接入

- **A1 人物参考录入**：从相册选真实肖像 → 压缩落私有目录（`files/preview-ref/`）→ preferences 记录路径与版本；可移除。仅发送给用户配置的图像生成服务；隐私说明同步。
- **A2 预览任务管线**：复用 `tasks` 表（`kind='try_on_preview'`，无 CHECK 约束可直接扩展）：输入版本（basis 单品集 + 穿法 + 参考版本）、状态机与启动恢复沿用 garmentTaskRunner 模式（含 interrupted 表达）、结果落盘 `files/previews/`、同条件比较、版本失效（改方案后旧预览标注过时，不冒充新方案结果）。
- **A3 预览 UI**：outfit 页星形按钮接通——预览面板（生成中/结果/失败重试/历史比较）；明示"AI 生成示意图，非真实试穿"。
- **A4 真实验证**：用户肖像 + 生成 + 真实试穿对照（用户线下），对照记录入文档。

## 轨 B：搭配推荐（实验先行）

- **B1 衣物档案导出（开发工具）**：数据工具页新增"导出衣物档案 JSON"（品类/名称/颜色/动态属性/测量，不含照片）——实验输入与调试两用。
- **B2 推荐实验**（`packages/experiments/src/outfit-recommendation/`）：档案 JSON + 场景 → 文本模型（DeepSeek/GLM，OpenAI 兼容）生成候选组合 → 搭配契约 v1.0.0 校验 → 通过率/缺口统计，多组跑批。
- **B3 证据评审**：通过率与缺口写记录，确定 APP 侧交互（候选复核方式）。
- **B4 推荐接入**：推荐任务（文本模型）→ 候选组合卡片复核 → 采用后进入搭配编辑/保存；模型未配置或失败保留手动组合。

## 轨 C：自动天气（可选联网）

- **C1** open-meteo（免 key）：城市 → 经纬度 + 当日天气；失败/离线保留手动输入。
- **C2** 天气卡片接入与降级表达。

## 验收（§7 M5 通过条件对照）

真实输出过适配层 + 契约校验（与 M3 同一套）；只用实际所选输入；离开页面不丢任务；改方案后旧结果不覆盖新方案；数据不足不出合身结论；预览与推荐分别按 A 线证据放行；未经验证能力不宣称可用。真实试穿对照记录为整体验收要件（用户参与）。

## 边界

- 预览不冒充真实试穿；数据不足不输出确定合身结论。
- 天气失败保留手动；不自动新增联网行为以外的服务。
- 真实取消/超时/重试策略：预览沿用 minimaxClient 120s 与任务状态机中断表达。
