## 需求基线（来自 docs/functions/AI上身预览.md §4）

- 保持**人物一致**：体型、比例、脸部、肤色、发型
- 保持**单品一致**：颜色、图案、领口、袖型、长度、关键结构
- **上身可信**：衣长、袖长、腰线、松量表现接近实际
- 输入：人物参考照 + 单品图（独立图或拼图+编号映射，实验要对比）

## 候选清单（三类）

| 类别 | 代表服务 | 人物/衣服一致性机制 | 成本量级 | 风险 |
| --- | --- | --- | --- | --- |
| ① 专用虚拟试穿 API | 阿里云百炼 OutfitAnyone、Kolors Virtual Try-On（快手）、Weshop 唯象（蘑菇群）等 | 专为试穿设计：人物照 + 服装图 → 试穿图，天然约束强 | 按张计费，通常较低 | 各家协议不同、可支持品类待实测；服务存续风险 |
| ② 通用图像编辑大模型 API | Gemini 2.x Flash Image（nano-banana 类）、GLM 后续图像模型、SeedEdit（字节）等 | 指令式编辑："让人穿上这件衣服"，一致性靠模型能力 | 按次计费，中等 | 一致性无保证——**这正是 A 线要测的**；可能改变脸部/细节 |
| ③ 开源自部署 | IDM-VTON、CatVTON、FitDiT 等 | 试穿专用开源模型，可控最强 | 需 GPU 自部署，前期成本最高 | 部署运维负担；效果需自行调 |
