## 衣物分析 2.0 真机验证与修复（2026-10-30）

2.0.0-draft 动态属性重构（见[实施计划](plans/2026-10-29-衣物分析字段与来源重构-实施计划.md)）已在真机走通全链路：APP 内照片 → 视觉模型分析 → 动态属性提取（7 项）→ 逐条用户确认 → SQLCipher 库持久化。验证中发现两个问题，本日修复：

- **分析状态不刷新**：执行器把任务终态落库后无人通知订阅者，详情页停留在「正在分析…」不更新（用户实测约 1 分钟后仍显示分析中；90 秒超时后任务实际已标 interrupted）。修复：`garmentTaskRunner` 新增 `onTaskSettled` 回调，领取/取消/stale/blocked/成功/失败/中断/启动恢复落库后均通知；`garmentAnalysisStore` 接 `notifyAnalysisChanged`。另补异常兜底：执行过程意外失败不再把任务留在 running（发送前 → failed，发送后 → interrupted）。
- **属性名输出英文**：模型沿用英文键（pattern/neckline 等）写入档案。修复：提示词（prompt v3）明确要求属性名用简体中文、禁止把顶层字段塞进 attributes；`normalizeAnalysisPayload` 对常见英文键做中文映射兜底，并对同名属性去重（保留最后一条），避免整体校验因重复被拒。已有英文属性行按设计保留为历史行，可手动删除或重新分析。
