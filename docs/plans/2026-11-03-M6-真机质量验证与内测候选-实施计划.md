## 批次 4：真机质量验证（Find X9 Pro，部分项目用户参与）

按开发计划 M6 工作清单执行，逐项记录通过/失败/未测：

- 视觉一致性：按页面与任务对照原型，含字体缩放、安全区域、键盘。
- 性能与内存：衣橱大量图片滚动与详情返回、预览图加载、滚动位置稳定。Find X9 Pro 为高端机，中端机结论不得由其代替（缺项如实登记）。
- 异常路径：断网、取消、权限拒绝、切后台与重启恢复、重试、低存储、演示数据隔离。
- 安全与资源：日志不含 API Key/密钥等敏感信息；删除后文件清理；系统云备份排除复核。
- 真人任务试用：项目用户按真实任务走完录入 → 推荐 → 预览 → 反馈，结论入报告。
