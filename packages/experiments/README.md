# @outfit/experiments

A 工作线（AI 可行性与试穿验证）的实验脚本位置：衣物理解、搭配推荐、上身预览分别跟踪。真实模型返回样本统一经 `@outfit/contract` 校验，与 APP 消费同一套契约。实验准备、样本与评价方法见 [docs/开发计划.md](../../docs/开发计划.md) A 工作线与 [docs/functions/AI上身预览.md](../../docs/functions/AI上身预览.md)。

运行：`pnpm --filter @outfit/experiments exec tsx <脚本>`（脚本待 A 线开始后添加）。
