> 定位：把 M4“工作块 4：任务执行接口”与 M5“衣物理解”的分析链路提前落地为可用骨架。**这不表示 M4 或 M5 完成**：M4 的升级演练、一致性与容量防御、删除联动真机复核等工作块未做；M5 的搭配推荐与上身预览接入未做。执行手册见 [衣物AI分析分批执行手册](plans/2026-10-29-衣物AI分析-分批执行手册.md)。

### 已实现（P1–P7）

- 契约：`packages/contract/src/garmentAnalysis.ts`，独立版本 `1.0.0-draft`。9 个属性用 `Field<T>` 三态（known/unknown/not_applicable）+ `targetStatus`/`unclearParts`，严格对象拒绝未知键、非 single 时属性必须 unknown；`parseGarmentAnalysis` 校验。

- **分析状态不刷新**：执行器把任务终态落库后无人通知订阅者，详情页停留在「正在分析…」不更新（用户实测约 1 分钟后仍显示分析中；90 秒超时后任务实际已标 interrupted）。修复：`garmentTaskRunner` 新增 `onTaskSettled` 回调，领取/取消/stale/blocked/成功/失败/中断/启动恢复落库后均通知；`garmentAnalysisStore` 接 `notifyAnalysisChanged`。另补异常兜底：执行过程意外失败不再把任务留在 running（发送前 → failed，发送后 → interrupted）。
