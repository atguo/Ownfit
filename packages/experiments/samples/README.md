# A 线样本拍摄指南

样本只存本机（`samples/` 已被 git 忽略），不入版本库。放好后运行实验脚本即可。

## 一、衣物理解样本（现在就要，6–10 件）

放入 `samples/wardrobe/` 目录。**一件衣服一张图**，文件名随意（会出现在实验记录里，建议有意义，如 `knit-cream-01.jpg`）。

拍摄要求（按重要性排序）：

1. **正面完整入镜**：整件衣服都在画面里，上下留一点空白，别裁掉领口或下摆
2. **光线均匀**：白天窗边自然光最好；避免逆光、强阴影和黄光
3. **背景整洁**：浅色墙面、床单或地面均可，避免花背景
4. **形态**：平铺或悬挂都行，尽量展现实际版型（不要团成一堆）
5. **格式**：jpg/png 都可以，手机原图即可，不用修图

⚠️ 故意留 1–2 张"不完美"的也可以（比如略暗、背面照）——A 线要测的就是模型的**未知与误识别边界**，完美样本测不出来。

## 二、上身预览样本（第二批，之后拍）

放入 `samples/person/`（人物参考）与 `samples/outfit-combos/`（组合对照）。

**人物参考照**（同一人拍 3–5 张）：
- 正面全身 1 张、侧面全身 1 张、半身 1 张
- 紧身一些的着装（能看出体型轮廓，不修改身材）
- 与衣物拍摄相同的光线要求；固定机位（靠墙或请人拍，标记机位高度）
- 表情姿态自然即可，不用修图

**组合对照**（为"AI 预览 vs 实际试穿"准备）：
- 选 2–3 套固定搭配（每套记下包含哪几件）
- 每套实际穿上拍正面全身照（与人物参考同机位同光线）
- 记录：拍摄日期、每套的穿法（如"前侧塞衣角"）

**同意与用途记录**（AI 上身预览文档 §8.3 要求）：参与者本人请在下方抄录确认一次，保存在本目录：

> 我同意将本目录中本人与衣物的照片用于本项目 AI 上身预览可行性实验（模型调用与效果评价），素材仅存本机、不入版本库，用完或项目终止后由我删除。确认人：____ 日期：____
